# homebrew-tap

Homebrew tap for [**gbar**](https://github.com/jaylann/gbar) — a general GitHub companion
in your macOS menu bar (pull requests, issues, CI, notifications, quick actions).

## Install

```bash
brew install --cask jaylann/tap/gbar
```

The cask installs the signed + notarized build, so it opens with no Gatekeeper prompt.

## Updating

`Casks/gbar.rb` is bumped automatically by gbar's release workflow on each tagged release —
don't edit it by hand.
